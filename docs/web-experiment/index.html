Lanius

A general-purpose programming language that makes compilation, optimization, and formal reasoning scale with compute.

View on GitHub → Read more ↓

Lanius is a systems programming language with a GPU-resident compiler and a formally verified compiler. Lanius's GPU compiler lexes, parses, typechecks, and emits instructions with massive parallelism on the GPU.

What it looks like

A prime sieve from sample_programs/bitset_prime_sieve.lani.

bitset_prime_sieve.lani
module app::main;
import core::bitset;
import core::i32;

fn main() -> i32 {
    // Mark composite numbers through 100 in four caller-owned words.
    let zero: u32 = 0;
    let composite: [u32; 4] = [zero, zero, zero, zero];
    let candidate: i32 = 2;
    while (candidate * candidate <= 100) {
        if (!get_or(composite, 101, candidate, false)) {
            let multiple: i32 = candidate * candidate;
            while (multiple <= 100) {
                if (!set(composite, 101, multiple)) { return 1; }
                multiple += candidate;
            }
        }
        candidate += 1;
    }

    let count: i32 = 0;
    let sum: i32 = 0;
    candidate = 2;
    while (candidate <= 100) {
        if (!get_or(composite, 101, candidate, false)) {
            count = saturating_add(count, 1);
            sum = saturating_add(sum, candidate);
        }
        candidate += 1;
    }
    print(count);
    print(sum);
    return 0;
}

A four-part plan

  1. Build the fastest compiler in the world

    A compiler that lexes, parses, type checks, and emits code entirely on the GPU compiles orders of magnitude faster than traditional compilers.

  2. Design expressive, explicit language features

    Algebraic data types and a powerful type system encode complex ideas directly and precisely.

  3. Define the language formally

    Formal proofs establish behavioral guarantees far beyond that of fixed-purpose static analyzers.

  4. Build the optimizer that scales

    An optimizer that uses learning and search efficiently outcompetes any other optimizer, given enough scale.

Status

Lanius is in an extremely early alpha. I would not recommend using it for any purpose.

Commands

laniusc --version
Print the compiler version.
laniusc doctor
Report as JSON whether laniusc can run.
laniusc check
Run frontend checks: lexing, parsing and type checking.
laniusc fmt [--check] <file>…
Format files in place, or only check them.
laniusc lsp serve --stdio
Start the language server (work in progress).

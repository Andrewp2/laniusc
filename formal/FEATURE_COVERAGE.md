# Formal feature coverage

This inventory is derived from `grammar/lanius.bnf`, the builtin declaration
table, `stdlib`, and the checked sample suite. “Represented” means the surface
syntax exists in Lean. “Dynamic” means resolved core programs can execute the
feature. “Pending” is an explicit gap, not an implicit or compiler-defined
behavior.

`CurrentFeatureAudit` fixes the audited grammar digest and its 290-production
partition, and accounts for all 68 compiler-materialized symbols against the
formal primitive, intrinsic, runtime-binding, wildcard, entrypoint, and range
path categories. Canonical bindings that are unavailable on this milestone
remain ordinary stdlib names rather than daemon-global compiler symbols.

The public dynamic semantics is fuel-independent and deterministic. Expression,
statement, and whole-program termination preserve the static type and runtime
memory invariants; evaluator fuel is only the totality mechanism used to
construct witnesses of that relation. `CurrentSemanticCoverage.current`
packages the checked cross-layer evidence, while `check-current-sources.sh`
rejects drift in the audited grammar, compiler language-symbol table, or stdlib
extern catalog.
